# Инструкция по запуску проекта

## 1. Установка Node.js
Для запуска проекта требуется установленная среда Node.js.
Скачать можно по ссылке: https://nodejs.org

## 2. Установка Expo CLI
Expo используется для запуска и тестирования мобильного приложения.

npm install -g expo-cli

## 3. Клонирование репозитория
Склонировать проект на локальный компьютер:

git clone https://github.com/ArmenSakanian/MyFirstApp

После клонирования перейти в директорию проекта:

cd MyFirstApp

## 4. Установка зависимостей проекта
Выполнить команду:

npm install

## 5. Установка зависимостей для навигации
Expo требует установки дополнительных модулей:

npx expo install react-native-screens react-native-safe-area-context

## 6. Запуск проекта
Запуск сервера Expo выполняется командой:

npx expo start --tunnel

После запуска появится QR-код.

## 7. Запуск на мобильном устройстве
1. Установить приложение Expo Go из Google Play или App Store.
2. Открыть Expo Go.
3. Отсканировать QR-код, который отображается после запуска проекта.
4. Приложение автоматически откроется на устройстве.
